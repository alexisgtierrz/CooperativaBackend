# Sistema de Gestión para Cooperativas de Servicios - Backend

Este repositorio contiene el backend del Sistema de Gestión Integral para Cooperativas de Servicios, desarrollado con Java, Spring Boot y PostgreSQL. La arquitectura está diseñada bajo un modelo multicapas (Controladores, Servicios y Repositorios).

## 🛠️ Tecnologías y Prerrequisitos

Para poder ejecutar este proyecto localmente, necesitas tener instalado lo siguiente en tu sistema:

1. **Java Development Kit (JDK) 17 o superior**
   - Descarga e instala desde [Adoptium](https://adoptium.net/) o el sitio oficial de Oracle.
   - Verifica la instalación abriendo una terminal y ejecutando: `java -version`

2. **PostgreSQL (14 o superior)**
   - Descarga e instala desde [postgresql.org](https://www.postgresql.org/download/).
   - Se recomienda instalar también **pgAdmin** o usar **DBeaver** para gestionar la base de datos visualmente.
   - Asegúrate de recordar la contraseña del usuario `postgres` que configures durante la instalación.

3. **Git**
   - Para clonar y gestionar las versiones del repositorio. Descarga desde [git-scm.com](https://git-scm.com/).

4. **IDE (Entorno de Desarrollo Integrado)**
   - Se recomienda **IntelliJ IDEA** (Community o Ultimate), **Eclipse** o **VS Code** con el pack de extensiones para Java.
